# 부동산 매물 이미지 프롬프트

부동산 화면의 매물 카드 사진을 만들 때 쓰는 프롬프트다. 지금은 모든 매물이 `assets/estate/_default.svg` 한 장을 함께 쓴다.

## 적용하는 법

1. 아래 프롬프트로 이미지를 만든다.
2. `assets/estate/<매물 id>.png` 로 저장한다. `.jpg`, `.webp` 도 된다. 예: `assets/estate/tower.png`
3. `node build.js` 를 실행하면 그 매물만 새 이미지로 바뀐다. 없는 매물은 계속 기본 이미지를 쓴다.

## 공통 규칙

- **크기** 1200×900 (4:3). 카드는 4:3, 펼친 카드는 16:7 로 잘라서 보여 주므로 건물이 가운데에 오게 한다.
- **용량** 장당 300KB 안쪽이 좋다 (휴대폰에서 받는다).
- **화풍** 게임 인물 일러스트와 어울리는 반실사 디지털 페인팅. 밝은 낮, 부드러운 햇빛, 맑은 하늘.
- **구도** 살짝 위에서 내려다본 3/4 시점. 사람·차는 작게, 또는 없음.
- **금지** 글자, 간판, 아파트 이름, 로고, 워터마크. 실제 브랜드 로고가 들어가지 않게 한다.

모든 프롬프트 앞에 아래 공통 문구를 붙인다.

```
semi-realistic digital painting for a mobile life-simulation game, Seoul, South Korea, bright daytime, soft sunlight, clear blue sky, slightly elevated three-quarter view, clean and detailed, no people in focus, no text, no signage, no logos, no watermark, 4:3
```
